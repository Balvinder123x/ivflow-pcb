### Tooling rules
kiutils 1.4.8 predates the KiCad 10 format and drops data when rewriting KiCad 10 files.
- Symbols: generated with kiutils, then normalised with `kicad-cli sym upgrade --force`.
- Footprints: generated with the `pcbnew` API (writes native KiCad 10 format directly).
- Never rewrite a file KiCad/the user has saved with kiutils.
- Schematic: generated by `scripts/make_schematic.py` with `scripts/kisexpr.py` (lossless
  S-expression reader/writer; official symbols are embedded flattened). The script verifies
  every pin against KiCad's exported netlist, then runs ERC.
- Previews: `kicad-cli sym/fp/sch export svg`, rasterised with headless Edge for checking.

### Library availability (official KiCad 10 libs)
All needed parts exist **except** `Transistor_FET:DMG2305UX` → Q1 = **AO3401A**.

## Design changes vs. original spec
- 2026-10-31: off-board parts plug in through connectors.
  - J_OLED: 1×4 male header, fixed order GND, VCC, SCL, SDA (jumper wires to module) → no custom part.
  - LED: D2 replaced by **J_LED** (JST-XH 2-pin, pin 1 = anode/+, pin 2 = cathode/−). R20 stays on board.
  - J_LDR unchanged (JST-XH 5-pin).
- 2026-11-01: power switch, buzzer and button also moved off-board (user decision):
  SW1 → **J6 POWER SW** (1 VSYS, 2 VSYS_SW, to a panel-mount switch ≥ 1 A),
  BZ1 → **J7 BUZZER** (1 + VSYS_SW, 2 − BUZ_N), SW2 → **J8 BUTTON** (1 BTN, 2 GND).
  All JST-XH 2-pin. D3 (flyback) and C6 (debounce) stay on the board.
  ⚠ J3/J6/J7/J8 are identical, so cables can be swapped. Most swaps are harmless, but the
  switch or button cable in J7 shorts VSYS_SW to GND through Q3 when the buzzer turns on,
  and the LED in J7 has no series resistor. User chose clear silkscreen labels (2026-11-01);
  a 3-pin keyed J6 is still possible if wanted.
- 2026-11-01: **TP4056 moved off-board** (user decision, so the PCB doesn't wait for the module
  to arrive; online pad layouts differ between sellers, lengths 22–29 mm). New **J9 CHARGER**,
  JST-XH 6-pin: 1 IN+ (VBUS), 2 IN− (GND), 3 B+ (BATT+), 4 B− (BATT−), 5 OUT+ (VBAT_P),
  6 OUT− (GND). U2 kept in schematic + BOM, `on_board no`, no footprint. The TP4056
  placeholder footprint was deleted. The user solders a 6-pin XH cable to the module's pads.
  Current through J9 ≤ ~1.3 A (1 A charge + load); XH is rated 3 A.
- 2026-11-01: SuperMini footprint from **published dimensions** (user decision; no source gives
  the first-pin offset → pins centred). Check the real board on a 1:1 printout before ordering.
- Reference designators: KiCad treats references without a number as unannotated, so the
  spec's connector names map to numbered refs (the Value field carries the name):
  J1 = J_BAT (BATTERY), J2 = J_LDR (LDR STRIP), J3 = J_LED (LED), J4 = J_OLED (OLED),
  J5 = J_EXP (EXPANSION), J6 POWER SW, J7 BUZZER, J8 BUTTON, J9 CHARGER. Power flag = #FLG01.
- Net names used for internal nodes: LED_EN (GPIO5), BUZ_EN (GPIO6), BAT_EN (GPIO7), BTN (GPIO10),
  EXP_IO20/21, LED_A, BUZ_N (buzzer −), Q2_D, Q2_G, Q3_G, BATT+/BATT− (battery side of U2).

## Power-path / safety review (2026-11-01)
TP4056 is only a charger; the board adds the rest:
- Load sharing: with USB present the system runs from VBUS through D1 and Q1 is off
  (gate = VBUS), so the TP4056 charges the battery only and terminates correctly. Without USB,
  R1 pulls Q1's gate low and the battery feeds VSYS through Q1.
- Battery protection: DW01A + 8205A on the module (over-discharge ~2.4 V, over-current, short);
  the board takes power from the protected OUT+/OUT−, and BAT− never touches GND.
- Firmware must add a low-battery shutdown (≈3.3–3.4 V via BAT_SENSE): DW01A's cut-off is too
  deep for Li-Po life, and AP2112K drops out below ≈3.5 V input at full load.
