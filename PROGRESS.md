### Tooling rules
kiutils 1.4.8 predates the KiCad 10 format and drops data when rewriting KiCad 10 files.
- Symbols: generated with kiutils, then normalised with `kicad-cli sym upgrade --force`.
- Footprints: generated with the `pcbnew` API (writes native KiCad 10 format directly).
- Never rewrite a file KiCad/the user has saved with kiutils.
- Schematic: generated by `scripts/make_schematic.py` with `scripts/kisexpr.py` (lossless
  S-expression reader/writer; official symbols are embedded flattened). The script verifies
  every pin against KiCad's exported netlist, then runs ERC.
- Previews: `kicad-cli sym/fp/sch export svg`, rasterised with headless Edge for checking.

### Library availability (official KiCad 10 libs)
All needed parts exist **except** `Transistor_FET:DMG2305UX` → Q1 = **AO3401A**.

## Design changes vs. original spec
- 2026-10-31: off-board parts plug in through connectors.
  - J_OLED: 1×4 male header, fixed order GND, VCC, SCL, SDA (jumper wires to module) → no custom part.
  - LED: D2 replaced by **J_LED** (JST-XH 2-pin, pin 1 = anode/+, pin 2 = cathode/−). R20 stays on board.
  - J_LDR unchanged (JST-XH 5-pin).
- Reference designators: KiCad treats references without a number as unannotated, so the
  spec's connector names map to numbered refs (the Value field carries the name):
  J1 = J_BAT (BATTERY), J2 = J_LDR (LDR STRIP), J3 = J_LED (LED), J4 = J_OLED (OLED),
  J5 = J_EXP (EXPANSION). Power flag = #FLG01.
- Net names used for internal nodes: LED_EN (GPIO5), BUZ_EN (GPIO6), BAT_EN (GPIO7), BTN (GPIO10),
  EXP_IO20/21, LED_A, BUZ_N (buzzer −), Q2_D, Q2_G, Q3_G, BATT+/BATT− (battery side of U2).
